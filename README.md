# 조재숙의 이혈테라피

12년 현장 경험으로 차별화된 이혈테라피 강의 및 건강상담

- 사이트: https://jaesuk-ear-therapy.netlify.app
- 분위기: 힐링·치유 (숲 초록 + 호수 청록 + 햇살 골드 + 아침 크림)

## 폴더 구조

```
jaesuk-ear-therapy/
├── index.html        페이지 내용 (글자 고치기는 여기서)
├── css/style.css     색·글꼴·배치 (맨 위 :root 에서 색 바꾸기)
├── js/main.js        움직임·햄버거 메뉴·이메일 표시
├── images/           사진 (영문 소문자 이름으로 넣기)
├── netlify.toml      Netlify 배포 설정 + 보안 헤더
└── .gitignore        GitHub에 올리지 않을 파일 목록
```

## 내 컴퓨터에서 미리보기

`index.html` 파일을 더블클릭하면 브라우저에서 열려요.

## 사진 바꾸기

1. 새 사진을 `images` 폴더에 영문 이름으로 넣어요. (예: `activity-5.jpg`)
2. `index.html`에서 사진 경로(`src`)와 설명(`alt`)을 바꿔요.

## 섹션 순서

히어로 → 소개(숫자) → 경력·저서 → 강의 분야 → 활동 사진 → 문의 → 푸터
